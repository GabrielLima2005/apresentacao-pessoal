
# 👨‍💻 Apresentação Pessoal — Gabriel Lima

Página web desenvolvida para apresentar meus interesses pessoais, hobbies e afinidades, utilizando conceitos fundamentais de desenvolvimento front-end.

O projeto foi criado como atividade acadêmica, com foco na construção de uma interface visualmente organizada, responsiva e interativa utilizando HTML5 e CSS3.

## 📌 Sobre o Projeto

A página apresenta informações sobre meus gostos e interesses, organizadas em cartões visuais com imagens, efeitos de interação e animações.

O objetivo é demonstrar conhecimentos básicos de estruturação de páginas web, estilização, organização de conteúdo e adaptação para diferentes tamanhos de tela.

## ✨ Funcionalidades

- Apresentação pessoal com título, fotografia e introdução.
- Seção de interesses organizada em cartões.
- Efeitos visuais ao passar o cursor sobre os cartões.
- Transições suaves e transformações com CSS.
- Animações automáticas utilizando `@keyframes`.
- Layout responsivo para diferentes dispositivos.
- Organização visual com CSS Grid.
- Comentários no código para explicar os efeitos implementados.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
|---|---|
| HTML5 | Estruturação e organização do conteúdo |
| CSS3 | Estilização, animações e responsividade |
| CSS Grid | Organização dos cartões em uma grade |

## 🚀 Como Executar o Projeto

Não é necessário instalar dependências ou configurar um servidor para visualizar a página localmente.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Para alterar o conteúdo, edite o arquivo HTML.
5. Para personalizar o visual, modifique o arquivo `style.css`.

### Clonar o repositório

```bash
git clone https://github.com/GabrielLima2005/apresentacao-pessoal.git
cd apresentacao-pessoal
```

## 🌐 Publicação

O projeto pode ser publicado gratuitamente na Vercel, utilizando o repositório do GitHub como fonte.

1. Acesse https://vercel.com/.
2. Entre com sua conta do GitHub.
3. Importe o repositório `apresentacao-pessoal`.
4. Configure o projeto como uma página estática, sem etapa de build.
5. Realize o deploy e obtenha a URL pública.

**Repositório:**  
https://github.com/GabrielLima2005/apresentacao-pessoal

**Demonstração online:**
